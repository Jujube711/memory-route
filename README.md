# 记忆航线

面向 13 至 15 岁学生的学习任务与挖空背诵原型。

## 功能

- 英语、地理、历史、生物任务展示
- 教材图片浏览器端 OCR 文字识别
- 手动选择答案并生成挖空背诵内容
- 孩子端横线预览、临时查看答案和录音入口
- 多条任务管理和轻度航线成长界面

## 页面

- `index.html`：孩子端
- `manager.html`：任务布置与挖空编辑端

## 当前能力

- 安卓手机全屏适配，可添加到主屏幕作为 PWA 使用
- 无需注册邮箱账号，孩子端打开即可使用
- 任务通过 Supabase 在线保存，并在孩子端实时同步
- 进入管理端、发布和删除任务时需要家庭通行码
- 录音背诵时持续显示挖空原文
- 安卓 Chrome 免费语音转文字，并逐项判断挖空答案

## 在线同步说明

GitHub Pages 负责托管页面，Supabase 负责保存任务数据。孩子端公开读取当前家庭任务；管理端写入和删除必须经过 Supabase 服务端函数验证通行码。

部署时先执行 `supabase-schema.sql`，再在 Supabase SQL Editor 单独设置通行码。真实通行码不得写入 `config.js`、GitHub 提交或公开文档。
