# 记忆航线

面向 13 至 15 岁学生的学习任务与挖空背诵原型。

## 功能

- 英语、地理、历史、生物任务展示
- 教材图片浏览器端 OCR 文字识别
- 手动选择答案并生成挖空背诵内容
- 孩子端横线预览、临时查看答案和录音入口
- 多条任务管理和轻度航线成长界面

## 页面

- `index.html`：孩子端
- `manager.html`：任务布置与挖空编辑端

## 当前能力

- 安卓手机全屏适配，可添加到主屏幕作为 PWA 使用
- 家庭邮箱账号注册与登录
- 同一家庭账号在管理端和孩子端实时同步任务
- 首次登录自动迁移浏览器里原有的本地任务
- 未登录时仍可使用本机模式
- 录音背诵时持续显示挖空原文
- 安卓 Chrome 免费语音转文字，并逐项判断挖空答案

## 云端部署

1. 在 Supabase SQL Editor 执行 `supabase-schema.sql`。
2. 将项目 URL 和 publishable key 填入 `config.js`。
3. 在 Supabase Auth 中启用 Email 登录；当前线上项目已关闭注册邮箱确认，注册后可直接登录。

数据表已启用 RLS，每个账号只能读写自己的任务。同一位家长与孩子需要在两台设备登录同一个家庭账号。
